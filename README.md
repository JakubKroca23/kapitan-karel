# Kapitan Karel — embeddable Ollama chat widget

TypeScript chat widget + Node proxy for a local Ollama instance (e.g. Docker). Embed into any site with one `<script>` tag.

## Architecture

```
Host page  →  widget.js  →  Node proxy (:3000)  →  Gemini (default) / Ollama
```

The browser never talks to Ollama directly (CORS / safety). The proxy streams OpenAI-compatible chat completions.

## Prerequisites

- Node.js 20+
- Ollama running (Docker or native) with at least one model pulled

Example Docker:

```bash
docker run -d -v ollama:/root/.ollama -p 11434:11434 --name ollama ollama/ollama
docker exec -it ollama ollama pull qwen2.5:3b
```

## Setup

```bash
npm install
npm run build -w widget   # first build so /widget.js exists
npm run dev               # proxy + widget watch
```

Open [http://localhost:3000/demo.html](http://localhost:3000/demo.html).

Production:

```bash
npm run build
npm start
```

## Environment

| Variable | Default | Description |
|---|---|---|
| `PORT` | `3000` | Proxy listen port |
| `OLLAMA_BASE_URL` | `http://127.0.0.1:11434` | Ollama base URL |
| `DEFAULT_MODEL` | `qwen2.5:3b` | Fallback model name |
| `CORS_ORIGIN` | `*` | Comma-separated origins, or `*` |

If the proxy runs in Docker on the same network as Ollama, set e.g. `OLLAMA_BASE_URL=http://ollama:11434`.

## Contsystem Manager

Manager (`cs-zakazky`) načte widget v autentizovaném portálu, když je nastaveno:

```bash
# cs-zakazky/.env.local
NEXT_PUBLIC_KAPITAN_KAREL_URL=http://localhost:3000
NEXT_PUBLIC_KAPITAN_KAREL_MODEL=qwen2.5:3b
```

Souběžně spusťte:

```bash
# terminál 1 — Ollama (pokud neběží)
# terminál 2 — tento repo
npm run dev

# terminál 3 — Manager (port 3001)
cd ../github/cs-zakazky && npm run dev
```

CORS default (`*`) stačí pro `http://localhost:3001`. V produkci nastavte
`CORS_ORIGIN` na origin Manageru.

## Embed

```html
<script
  src="http://localhost:3000/widget.js"
  data-api="http://localhost:3000"
  data-model="qwen2.5:3b"
  data-title="Kapitán Karel"
  data-welcome="Ahoj — jsem Kapitán Karel. Jak můžu pomoct?"
  data-actions='[{"label":"Co je na stránce?","prompt":"Shrň obsah stránky."}]'
  data-system="Jsi Kapitán Karel, věcný asistent. Odpovídej stručně česky."
  async
></script>
```

| Attribute | Description |
|---|---|
| `data-api` | Proxy base URL (defaults to script origin) |
| `data-model` | Ollama model name |
| `data-title` | Panel title (default: Kapitán Karel) |
| `data-system` | Optional system prompt |
| `data-welcome` | Fixed welcome text (not generated by the model) |
| `data-actions` | JSON array of `{ label, prompt? \| href? }` quick buttons |

Host API after load: `window.KapitanKarel.setPageContext(text)`, `.setActions([...])`, `.setWelcome(text)`.

Each chat request injects a live scrape of the current page (plus optional host context). Navigation via action `href` dispatches `kk:navigate` (cancelable).

## API

- `GET /api/health` — Ollama connectivity + model list
- `POST /api/chat` — body `{ messages, model? }`, SSE stream (OpenAI chunk format)
- `GET /widget.js` — built embed bundle
- `GET /demo.html` — sample host page
